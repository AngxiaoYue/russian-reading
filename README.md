# 字里行间 · Между строк

A small, invitation-based Russian reading evaluation.

This public repository contains the web page only. The current six pairs are hand-written demonstration texts, not model outputs or evidence of steering performance. Scoring records and method mappings are not stored in this repository.

Pages: `/` is the 2026-09 page with six demonstration pairs, which sends results when the reviewer submits them. `/review-2026-10/` saves the reviewer's answers to the study owner's backend after each item. Both need a valid invitation link to send anything; without one, answers stay in the browser. The embedded Supabase key is a publishable key; data access is restricted by the backend.

Font licenses are embedded in the HTML.
